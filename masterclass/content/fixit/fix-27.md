checks:
  - Run your fingernail across it. Does it catch?
  - Hold the light low across it. How deep does it look?
  - Is it a rock chip?
causes:
  - A scratch that catches a nail is deeper than polish can reach. It stays.
  - Rock chips usually can't be fully removed.
  - Polish levels out swirls. The test spot decides what comes out.
steps:
  - Run your fingernail across it while the customer watches.
  - Nail catches? Tell them it stays.
  - Photograph it before anything touches the car.
  - Read the script out loud, word for word.
  - Get the signature.
  - Run the test spot, split in half.
  - Show the customer both halves.
  - Quote the tier the test spot proved.
