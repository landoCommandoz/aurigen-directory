  - "Find 10 marks: swirls or scratches."
  - Photograph each mark before you touch it.
  - Run your fingernail across each scratch.
  - "Call each one out loud. Nail catches: it stays. No catch: the test spot decides."
  - Never say a mark will come out.
  - Lando checks each call against his.
